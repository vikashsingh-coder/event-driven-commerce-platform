# Step 2 — Initialize Node Project

Create root package:

```bash
pnpm init
```

This creates:

```text
package.json
```

---

# Step 3 — Install pnpm Workspace

We will use **pnpm workspaces** because:

- Faster dependency installation
- Better monorepo management
- Shared package linking
- Enterprise-friendly

Create:

```text
pnpm-workspace.yaml
```

Content:

```yaml
packages:
  - "services/*"
  - "packages/*"
```

Now pnpm understands:

```text
services/*
packages/*
```

as workspace projects.

---

# Step 4 — Update Root package.json

Root package responsibilities:

- Manage scripts
- Manage common dependencies
- Manage tooling

  "version": "1.0.0",

  "scripts": {

# Step 6 — Create Base TypeScript Configuration

Create:

```text
tsconfig.base.json
```

Content:

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "NodeNext",
    "moduleResolution": "NodeNext",

    "strict": true,

    "esModuleInterop": true,
    "skipLibCheck": true,

    "forceConsistentCasingInFileNames": true,

    "resolveJsonModule": true,

    "sourceMap": true,

    "declaration": true
  }
}
```

All services inherit this.

Example:

```json
{
  "extends": "../../tsconfig.base.json"
}
```

# Step 7 — Configure ESLint

Install:

```bash
pnpm add -D eslint typescript-eslint
```

Create:

```text
eslint.config.js
```

Initial configuration:

```javascript
import tseslint from "typescript-eslint";

export default tseslint.config({
  files: ["**/*.ts"],
  extends: [...tseslint.configs.recommended],
  rules: {
    "@typescript-eslint/no-unused-vars": "error",
  },
});
```
